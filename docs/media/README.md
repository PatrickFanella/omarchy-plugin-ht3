# TOZO HT3 media

- `../../preview.png`: 1536 × 1024 edited preview, made with the built-in imagegen tool from a desktop capture of the installed plugin.
- `controls.png`: 402 × 617 unretouched region capture of the connected popup.

Captured on Kvant on October 5, 2026 UTC (October 4 in Chicago). The headset
was connected and reported 100% battery and 57% playback volume. The preview
shows transparency mode; the close-up shows ANC. The EQ curve came from the
headset. No control changes were made to prepare the media.

The preview uses generated presentation artwork and a reconstructed rendering
of the captured interface. It is not a pixel-exact screenshot or evidence of
other firmware support. Use the close-up for the actual installed appearance.
The captured installation and the current repository can differ; this media
does not extend the compatibility claims in the main README.

Imagegen brief: extract only the connected HT3 popup; remove surrounding apps,
conversations, desktop status and pet; preserve controls, values and selected
transparency mode; place the popup on a dark violet landscape with the title
“TOZO HT3”, “for Omarchy”, and the labels “Volume & mute”, “Noise control” and
“10-band hardware EQ”; mark it “Edited desktop capture”.

The media is distributed under the repository's MIT license. Raw desktop
captures containing other apps are excluded from the repository.
